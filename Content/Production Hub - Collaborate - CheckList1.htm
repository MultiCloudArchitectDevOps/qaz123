CheckList

Access the CheckList

To access the CheckList page, follow the steps below:

  1. Navigate to Grid Menu button located on the upper left side of the window. Click the Grid Menu button.

Grid Menu button

  1. The Grid Menu gets expanded.

Expanded Grid Menu

  1. Click the Production Hub expand button.

Production Hub expand button

  1. Click the Collaborate button.

Collaborate button

  1. The Collaborate window opens.

Collaborate window

  1. Click the CheckList tab.

CheckList tab

  1. The CheckList window opens.

CheckList window

Add Checklist

The Add Checklist feature allows users to create/add a new Checklist.

To create/add a new Checklist, follow the steps below:

  1. To access the CheckList page, follow steps 1 to 7 of the Access the CheckList process under the Production Hub/Collaborate/CheckList section of the user guide.
  1. Click the + Add Checklist button.

+ Add Checklist button

  1. The Add a New Checklist window opens.

Add a New Checklist window

  1. Click the Title field and enter the title as required.
Note:

Fields with an asterisk mark (*) are Mandatory fields.

Title field

  1. Click the Description field and enter the description as required.

Description field

  1. By default, the Checklist Mapping section shows that the Map by Document Type radio button is selected.

Checklist Mapping section

  1. If the user wants to Map the Checklist by Document Type, click the Document Type drop down and select the document type from the list as applicable. Users can choose only one Document Type at a time.
Note:

Users can create a Checklist once for a particular Document Type. Once the user creates a Checklist for a particular Document Type, that Document Type gets removed from the Document Type drop down.

Document Type drop down

  1. If the user wants to Map the Checklist with the default Checklist, users can click the Default Mapping radio button.
Note:

If the user has already created the default checklist, then the Checklist Mapping Default radio button gets disabled and shows an error like a default checklist already exists. Please edit the existing one.

Checklist Mapping using the Default Mapping checklist

  1. Click the Title field and enter the title as required.

Title field

  1. Click the  Description field and enter the description as required.

Description field

  1. The IsMandatory function provides the Yes or No options. Users can select either Yes or No as applicable. To select Yes or No, click either of the radio buttons.

IsMandatory radio buttons

IsMandatory radio button selection

  1. Click the Field Type drop down and select the field type from the list as applicable. Users can choose only one Field Type at a time.

Field Type drop down

  1. If the user wants to add one more Checklist item, click the + Add button.

+ Add button

  1. The new empty Checklist Item section gets added. Users can follow the above steps from 9 to 12 to configure the empty fields.

Newly added Checklist Item section/Empty fields

  1. If the user wants to delete any Checklist Item section, click the X button.

X button

  1. The item/row gets deleted.

Updated Checklist Items list

  1. Once the users are done with their configuration, click the Save button.

Save button

  1. The Window gets reloaded, and the newly added Checklist appears at the top of the list.

Newly added Checklist

Preview Checklist

The Preview Checklist functionality allows users to see the items inside the selected Checklist.

To preview the selected Checklist, follow the steps below:

  1. To access the CheckList page, follow steps 1 to 7 of the Access the CheckList process under the Production Hub/Collaborate/CheckList section of the user guide.
  1. Select the Checklist. To select the Checklist, click the checkbox. The checkbox gets selected with the checkmark icon, and the row gets selected. Users must select only one Checklist at a time. More than one Checklist selection is not allowed.

Checklist selection

  1. Click the Preview Checklist icon.

Preview Checklist icon

  1. The Checklist Details pop-up window opens. Users can see/view all the listed Checklist items and their details.

Checklist Details pop-up window

  1. Click the (X) icon to close the Checklist Details pop-up window.

X icon

Edit Checklist

The Edit Checklist functionality allows users to edit/add/modify/update any details from any field(s)/drop down(s) from the selected Checklist.

To edit/add/modify/update any details from any field(s)/drop down(s) from the selected Checklist, follow the steps below:

  1. To access the CheckList page, follow steps 1 to 7 of the Access the CheckList process under the Production Hub/Collaborate/CheckList section of the user guide.
  1. Select the Checklist. To select the Checklist, click the checkbox. The checkbox gets selected with the checkmark icon, and the row gets selected. Users must select only one Checklist at a time. More than one Checklist selection is not allowed.

Checklist selection

  1. Click the Edit icon.

Edit icon

  1. The Edit Checklist window opens.

Edit Checklist window

  1. To edit/add/modify/update any details from any field(s)/drop down(s) from the Checklist, follow the steps 4 to 18 of the Add Checklist procedure under the Production Hub/Collaborate/Checklist section of the user guide.

Delete Checklist

The Delete Checklist functionality allows users to delete the selected Checklist.

To delete the selected Checklist, follow the steps below:

  1. To access the CheckList page, follow steps 1 to 7 of the Access the CheckList process under the Production Hub/Collaborate/CheckList section of the user guide.
  1. Select the Checklist. To select the Checklist, click the checkbox. The checkbox gets selected with the checkmark icon, and the row gets selected. Users must select only one Checklist at a time. More than one Checklist selection is not allowed.

Checklist selection

  1. Click the Delete Checklist icon.

Delete Checklist icon

  1. The confirmation message pop-up window opens. Click the Close button.

Confirmation message pop-up window

  1. The selected Checklist gets deleted successfully from the list.

Updated list
