Advanced Search with Find & Replace

The Advanced Search with Find & Replace functionality allows users to Apply Search, Find All, and Replace All as required.

To utilize the Advanced Search with Find & Replace functionality, follow the steps below:

  1. To access the Digital Content Manager page, follow steps 1 to 5 of the  Access the Digital Content Manager process under the Authoring Hub section of the user guide.
  1. Click the Advanced Search with Find & Replace icon.

Advanced Search with Find & Replace icon

  1. The Advanced Search with Find & Replace pop-up window appears.

Advanced Search with Find & Replace pop-up window

  1. If the user wants to find a specific Rule with specific Search Criteria, navigate to the Search Criteria section, click the Select Column drop-down, and select the column name from the list as applicable. Users can choose only one Column at a time.

Select Column drop-down

  1. Click the Operator drop-down, and select the operator from the list as applicable. Users can choose only one Operator at a time.

Operator drop-down

  1. Click the Enter Value field and enter the value as required or applicable.

Enter Value field

  1. If the user wants to add one more condition, they can click the + Add condition button.

+ Add condition button

  1. The new row gets added.
Note:

If users want to fill in/add data to the empty field(s)/drop-down(s), they can refer to the above steps from 4 to 6.

Newly added row

  1. If the user wants to remove the row(s), they can click the Remove (x) icon.

Remove (x) icon

  1. The row(s) gets removed.

Updated Search Criteria section

  1. Once the users are done with their configuration(s), click the Apply Search button.

Apply Search button

Plan Preview Selection

The Plan Preview Selection functionality allows users to select the Contract Number, Group Plan Number, Rule ID, and Row Version Number of the Plan to preview either in English or Spanish language.

To Plan Preview Selection, follow the steps below:

  1. To access the Digital Content Manager page, follow steps 1 to 5 of the  Access the Digital Content Manager process under the Authoring Hub section of the user guide.
  1. Click the Plan Preview Selection icon.

Plan Preview Selection icon

  1. The Plan Preview Selection pop-up window appears.

Plan Preview Selection pop-up window

  1. By default, the Total Estimated Plan Hit field displays the total estimated plan hit count.

Total Estimated Plan Hit field

  1. By default, the Contract Number Hit field displays the total contract number hit count.

Contract Number Hit field

  1. By default, the Group Plan Number Hit field displays the total group plan number hit count.

Group Plan Number Hit field

  1. Click the Contract Number drop-down and select the contract number from the list as applicable. Users can choose only one Contract Number at a time.
Note:

Users can utilize the Search contract number option.

For example:

Enter a valid Contract Number in the Search contract number box.

Users can see that the appropriate Contract Number for the entered contract number gets searched and appears on the window. Click the Contract Number.

Contract Number drop-down

Search contract number box

Searched Contract Number

  1. Click the Group Plan Number drop-down and select the group plan number from the list as applicable. Users can choose only one Group Plan Number at a time.
Note:

Users can utilize the Search group plan numt option.

For example:

Enter a valid Group Plan Number in the Search group plan numt box.
Users can see that the appropriate Group Plan Number for the entered group plan number gets searched and appears on the window. Click the Group Plan Number.

Group Plan Number drop-down

Search group plan numt box

Searched Group Plan Number

  1. Click the Rule ID field and enter the rule id as applicable.

Rule ID field

  1. Click the Row Version Number drop-down and select the row version number from the list as applicable. Users can choose only one Row Version Number at a time.

Row Version Number drop-down

  1. The English text area shows the sample English content for the Plan Preview. This text area will display the English version of the Plan Details, Terms, Conditions, and other relevant information that needs to be communicated to the user.

English text area

  1. Click the Spanish tab. The Spanish text area shows the sample Spanish content for the Plan Preview. This text area will display the Spanish version of the Plan Details, Terms, Conditions, and other relevant information that needs to be communicated to the user.

Spanish text area

  1. Once users are done with their Plan Preview, click the Cancel button to close the pop-up.

Cancel button
