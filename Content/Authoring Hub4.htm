Edit Rule

The Edit Rule functionality allows users to edit an existing Rule as required.

To edit an existing Rule, follow the steps below:

  1. To access the Digital Content Manager page, follow steps 1 to 5 of the  Access the Digital Content Manager process under the Authoring Hub section of the user guide.
  1. To select the Rule ID, click the checkbox. The checkbox gets selected with the checkmark icon. Users can choose only one Rule at a time. The row gets highlighted after the selection.
Note:

Users can utilize the AI Assisted Rule Search option.

For example:

Enter a valid Rule ID in the AI Assisted Rule Search box and users can see that the appropriate Rule for the entered Rule ID gets searched and appears on the window.
