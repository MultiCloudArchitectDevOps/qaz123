Collaborate

The Collaborate functionality automates and streamlines the end-to-end review process of documents generated within Simplify Docs. The Collaborate dashboard will significantly improve the overall routing, tracking, and management of feedback between a group of business users.

Access the Collaborate

To access the Collaborate page, follow the steps below:

  1. Navigate to Grid Menu button located on the upper left side of the window. Click the Grid Menu button.

Grid Menu button

  1. The Grid Menu gets expanded.

Expanded Grid Menu

  1. Click the Production Hub expand button.

Production Hub expand button

  1. Click the Collaborate button.

Collaborate button

  1. The Collaborate window opens.

Collaborate window

Collaborate Dashboard

The Collaborate dashboard is designed to streamline the review process, providing details on the Review Stages, Status, Version, and the Users involved. This functionality represents a revolutionary change in document review and version management.

The Collaborate dashboard consists of key features:

  • Collaborate
  • Dashboard
  • Logs
  • User Management

Each feature offers specific details about the document review process.

Collaborate

The Collaborate window displays a list of all Documents shared with the client team’s reviewers for their review. Users can use this window, which provides detailed information about each document under review, including:

  • Id
  • Collateral Type
  • Font Type
  • Product Name
  • Folder Name
  • Effective Date
  • Version
  • Workflow State
  • Estimated Completion
  • Collaborate Version
  • Product Link
  • Review Summary
  • Previous Version
  • Assigned To
  • Reviewers Involved
  • Queued By
  • Queued Date
  • Total Review Count
  • Draftable Compare
  • Update Status
  • Email Status

Definition of Review Workflow Status

  1. Error: In this Workflow state, the Error status appears when the Collateral fails.

Error Status

  1. Publishing: In this Workflow state, the system generates the Document(s) and publishes it online for Reviewers to access.

Publishing Status

  1. Terminated: In this Workflow state, the Document review Workflow process is terminated. Users can terminate the review Workflow at the Publishing Workflow status.

Terminated Status

  1. Ready For Review: In this Workflow state, the Document is ready for the user's Feedback/Comments. Users can click on the Product Link to open and review the Document(s) in Review mode.

Ready For Review Status

  1. Review Completed: In this Workflow state, once a review is added to the document, the user transitions the document to the Review Completed state. In this state, all reviews are finalized, and any feedback or comments added to the document are consolidated into a Review Summary. All feedback and comments are recorded and saved within the Review Summary section.

Review Completed Status

  1. ML Updates In-Progress: In this workflow state, the Docs Config team works on incorporating the comments/feedback provided by the reviewers in the Master Lists (ML) in the Simplify Docs platform.

ML Updates In-Progress Status

  1. ⁠Updates Ready: In this Workflow state, the Product Configuration team incorporates the review and formatting changes and transitions the document to the Updates Ready state after the Internal Review. Users can be allowed to republish the document and review the modifications.

Updates Ready Status

  1. Re-open Review: This Workflow state lets users reopen documents that have already completed the review process and are in the review completed state so that they can incorporate additional reviews or revisions.

Re-open Review Status

  1. Cancel: In this Workflow state, selecting the Cancel state at the Ready For Review Workflow State cancels the Workflow. Choosing the Cancel status after the Ready For Review state initiates the cancellation of the current Workflow and rolls back the changes.

Cancel Status

  1. RollBack In Progress: In this Workflow state, when users initiate the cancellation of the Workflow, the Workflow Dashboard gets updated to reflect the current status, indicating that the rollback process is underway.

RollBack In Progress Status

  1. Approve: In this Workflow state, the Document gets approved, indicating that no further updates are required.

Approve Status

Upload External Document

This functionality allows users to upload any external document.

To Upload External Document, follow the steps below:

  1. To access the Collaborate page, follow steps 1 to 5 of the Access the Collaborate process under the Production Hub/Collaborate/Collaborate section of the user guide.
  1. Click the Upload External Document icon.

Upload External Document icon

  1. The Upload External Document pop-up window appears.

Upload External Document pop-up window

  1. Click the Name field and enter the name as required.
Note:

Fields with an Asterisk Mark (*) are mandatory fields.

Name field

  1. Click the Collateral Name drop-down and select the collateral name from the list as applicable. Users can choose only one Collateral Name at a time.

Collateral Name drop-down

  1. Click the Font drop-down and select the font type from the list as applicable. Users can choose only one Font at a time.

Font drop-down

  1. Click the Folder Name field and enter the folder name as required.

Folder Name field

  1. Click the Folder Version field and enter the folder version as required.

Folder Version field

  1. Click the Product Name field and enter the product name as required.

Product Name field

  1. Click the Calendar and select the Effective Date from the Calendar.
Note:

Users can enter the Effective Date manually.

Effective Date selection

  1. Click the Calendar and select the ECD from the Calendar.
Note:

Users can enter the ECD manually.

ECD selection

  1. Click the Choose File button.

Choose File button

  1. The Open pop-up window appears. Select the appropriate file from your local system. The file gets highlighted after the selection. Users can choose only one file at a time.

File selection

  1. Click the Open button

Open button

  1. The file gets added/uploaded/selected.

Added/uploaded/selected file

  1. Click the Publish To Collaborate button.

Publish To Collaborate button

  1. The confirmation Message pop-up window appears. Click the Close button.
  1. The document gets uploaded successfully and added to the top of the window.

Newly Uploaded External Document
