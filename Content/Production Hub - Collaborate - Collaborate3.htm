Download Workflow Process

The Download Workflow Process displays collaboration requests. The Download functionality allows users to download the selected or all the Workflow Process from the Collaborate Dashboard to their local system in Excel format for easy access.

To download the Workflow Process, follow the steps below:

  1. To access the Collaborate page, follow steps 1 to 5 of the Access the Collaborate process under the Production Hub/Collaborate/Collaborate section of the user guide.
  1. Select the Collab Id(s)/Process Id(s) from the list. To select the Collab Id(s)/Process Id(s), click the checkbox(s), and the checkbox(s) gets selected with a checkmark icon. Users can choose one or more Collab Id(s)/Process Id(s) at a time.
Note:

The checkbox is enabled only for the assigned document Workflow; checkboxes for other Workflow Processes will be disabled.

Users can utilize the Search documents, contract numbers, or plan names option to find the appropriate Product from the list.

For example:

Enter a valid Product Name in the Search documents, contract numbers, or plan names search box. The Product Name gets searched and appears on the window.

Terminate Workflow Process

The Remove functionality allows users to Terminate the Workflow Process in the publishing state.

To terminate the Workflow Process, follow the steps below:

  1. To access the Collaborate page, follow steps 1 to 5 of the Access the Collaborate process under the Production Hub/Collaborate/Collaborate section of the user guide.
  1. Select the Collab Id(s)/Process Id(s) from the list. To select the Collab Id(s)/Process Id(s), click the checkbox(s), and the checkbox(s) gets selected with a checkmark icon. Users can choose one or more Collab Id(s)/Process Id(s) at a time.
Note:

The checkbox is enabled only for the assigned document Workflow; checkboxes for other Workflow Processes will be disabled.

Only the assigned users and the users who published the flow can terminate the review Workflow Process.

Users can utilize the Search documents, contract numbers, or plan names option to find the appropriate Product from the list.

Users can terminate the Workflow only when the Document is in Publishing Workflow Status.

For example:

Enter a valid Product Name in the Search documents, contract numbers, or plan names search box. The Product Name gets searched and appears on the window.

Product Name selection

Remove icon

  1. The Processes terminated successfully pop-up appears.

Processes terminated successfully pop-up

  1. The process gets terminated for the selected Workflow on the Collaborate dashboard.

Select Column

To hide/unhide the column(s), follow the steps below:

Review Process Workflow

  1. Once the user submits the Plan Document for review and publishing, the Document gets queued in Collaborate. The Document Status is in Publishing, and the Document Version is minor.
Note:

When the Document Workflow status shows Publishing, the Document mode is View only.

The system sends an email notification to all users involved in the Document Review Process at each review stage.

When the Reviewers receive an email notification, they can review the Document through the Reviewers Dashboard. To access and understand the steps in the Reviewers Dashboard, refer to the Reviewers Dashboard process under the Production Hub section of the user guide.

Published Document

  1. Once the background process completes, the status of the published document automatically changes to Ready For Review.

Ready to Review

  1. Click the Product Link icon to open the Document for review.
Note:

The Product Link column contains two links. One link opens the Document directly at the SharePoint location, and the other link opens the Document in the Desktop application.

Product Link icon
