Digital Content Manager

Access the Digital Content Manager

To access the Digital Content Manager page, follow the steps below:

  1. Navigate to Grid Menu button located on the upper left side of the window. Click the Grid Menu button.

Grid Menu button

  1. The Grid Menu gets expanded.

Expanded Grid Menu

  1. Click the Authoring Hub expand button.

Authoring Hub expand button

  1. Click the Digital Content Manager button.

Digital Content Manager button

  1. The Digital Content Manager window opens.

Digital Content Manager window

Create Rule

The Create Rule functionality allows users to create a new rule based on their requirements.

To create a new Rule, follow the steps below:

  1. To access the Digital Content Manager page, follow steps 1 to 5 of the  Access the Digital Content Manager process under the Authoring Hub section of the user guide.
  1. Click the + Create Rule button.

+ Create Rule button

  1. The Create Rule window opens.

Create Rule window

  1. The Rule ID, Row Version, Added By, and Added On fields are disabled and cannot be edited by users.
Note:

The fields could change based on clients.

Disabled fields

  1. Click the Rule ID Type drop-down menu and select either Model or MCare.

Rule ID Type drop-down

  1. Click the Source Mapping drop-down and select the source mapping from the list as applicable. Users can choose only one Source Mapping at a time.

Source Mapping drop-down

  1. Click the Effective Date (Plan Year) drop-down and select the effective date (plan year) from the list as applicable. Users can choose only one Effective Date (Plan Year) at a time.

Effective Date (Plan Year) drop-down

  1. Click the Is Tabular checkbox, and it gets selected with a checkmark icon.
Note:

Users should select Is Tabular only when the content in the Rule is going to be within a table.

If the user wants to select the Select All checkbox, click the Select All checkbox, and it gets selected with a checkmark icon.

If the user wants to select the Released Content checkbox, click the Released Content checkbox, and it gets selected with a checkmark icon.

Is Tabular checkbox

  1. Once the user selects the Is Tabular checkbox, the Select Service ID button gets enabled.

Enabled Select Service ID button

  1. Click the Select Service ID button.

Select Service ID button

  1. The Select Service ID pop-up window appears.

Select Service ID pop-up window

  1. Click the respective Mapping that the user wants to add. Once the user clicks Mapping, the row gets highlighted after the selection. Users can choose only one Mapping at a time.

Mapping selection

  1. Click the Select button.

Select button

  1. The Reference ID of the selected Mapping gets added under the Service Id field.

Reference ID/Service Id

  1. Click the Template Name drop-down and select the template name from the list as applicable. Users can choose only one Template Name at a time.

Template Name drop-down

  1. Click the Chapter Name drop-down and select the chapter name from the list as applicable. Users can choose only one Chapter Name at a time.
Note:

Users can also enter the Chapter Name manually.

Chapter Name drop-down/field

  1. Click the Section Name field and enter the section name as required.

Section Name field

  1. Click the Sub section Name field and enter the sub section name as required.

Sub section Name field

  1. Click the Generate Key button.
Note:

If users have already generated a Key and want to use it, they can click the Generate Key field and update the existing Key.

Generate Key button

Generate Key field

  1. The Generate Key pop-up window appears.

Generate Key pop-up window

  1. The Selected Expression section allows users to add an Expression, a Group, or both, as required.

Selected Expression section

  1. If the user wants to add an expression, click the + Add Expression button.
Note:

+ Add Expression allows users to add a Logical Condition(s) or Expression(s) to a Rule. An Expression is a statement that evaluates to either True or False and defines the criteria that must be met for the associated action(s) to execute.

+ Add Expression button

  1. The new expression row gets added.

Newly added expression row

  1. Click the Select Field button.

Select Field button

  1. The pop-up window appears and, by default, shows the Design aliases list.

Design aliases

  1. Click/select the Design Alias or FullName as required. The Design Alias or FullName gets highlighted after the selection. Users can choose only one Design Alias or FullName at a time.
Note:

Users can use the Search option to search for the Design Alias or FullName. Users can enter the Design Alias or FullName in the Search box and press Enter. The entered Design Alias or FullName appears on the window. Users can select the Design Alias or FullName.

Design Alias or FullName selection

Search Option & Searched Result

  1. If the user wants to select the global rule, click the Global Rule radio button.

Global Rule radio button

  1. The Global Rule list appears.

Global Rule list

  1. Click/select the FullName or Definition as required. The FullName or Definition gets highlighted after the selection. Users can choose only one FullName or Definition at a time.
Note:

Users can use the Search option to search for the FullName or Definition. Users can enter the FullName or Definition in the Search box and press Enter. The entered FullName or Definition appears on the window. Users can select the FullName or Definition.

FullName or Definition selection

Search Option & Searched Result

  1. Once the user selects the Design Alias or Global Rule, click the Save button.

Save button

  1. The selected Design Alias or Global Rule gets added.

Newly added Design Alias or Global Rule

  1. Click the Select Operator drop-down and select the operator from the list as applicable. Users can choose only one Operator at a time.

Select Operator drop-down

  1. Click the Enter Value field and enter the value as applicable.

Enter Value field

  1. If the user wants to add one more expression, they can click the + Add Expression button.

+ Add Expression button

  1. The new row gets added.
Note:

If users want to configure the newly added expression row, refer to the above steps from 24 to 33.

Newly added row

  1. If the user wants to remove the expression row, they can click the X button.

X button

  1. The expression row gets deleted.

Updated Selected Expression section

  1. By default, the AND expression is selected. If the user wants to change the expression, they can click either the AND or OR button.

AND/OR expression selection

  1. If the user wants to add a group, click the + Add Group button.
Note:

+ Add Group allows users to create a set of Condition(s) that are evaluated together. Groups combine multiple expressions using logical operators like AND or OR.

+ Add Group button

  1. The new group row gets added.

Newly added group row

  1. If users want to add a new expression row, refer to the above steps from 22 to 38.
  1. If the user wants to remove the group row, they can click the X Remove Group button.

X Remove Group button

  1. The group row gets deleted.

Updated Selected Expression section

  1. Once the user creates the expression(s) as required, click the Save button.

Save button

  1. The generated Key gets added to the Generate Key field.

Generated Key field

  1. Click the Service Group field and enter the service group as required.

Service Group field

  1. Click the Description field and enter the description as required.

Description field

  1. Click the RTF Names field and enter the RTF name as required.

RTF Names field

  1. Click the Tier drop-down field and select the tier from the list as applicable. Users can choose only one Tier at a time.

Tier drop-down

  1. Click the empty English field and enter/configure the content in English as required or applicable.

English field

  1. Click the empty Spanish field and enter/configure the content in Spanish or any other language as required or applicable.

Spanish/ any other language field

  1. Once the users are done with their configuration(s), navigate to the upper right corner of the window and click the Save button.

Save button

  1. The window reloads and navigates back to the Digital Content Manager window. The new Rule gets created successfully and added to the top of the list.

Newly created Rule
