Generate Documents

Access the Generate Documents

To access the Generate Documents page, follow the steps below:

  1. Navigate to Grid Menu button located on the upper left side of the window. Click the Grid Menu button.

Grid Menu button

  1. The Grid Menu gets expanded.

Expanded Grid Menu

  1. Click the Production Hub expand button.

Production Hub expand button

  1. Click the Generate button.

Generate button

  1. The Generate Documents window opens.

Generate Documents window

Generate and Publish the Document(s)

To Generate, Queue, and Publish the selected Document(s), follow the steps below:

  1. To access the Generate Documents page, follow steps 1 to 5 of the Access the Generate Documents process under the Production Hub/Generate/Generate Documents section of the user guide.
  1. By default, the GENERATE drop-down displays the Document. Users can click the GENERATE drop-down and select the generate from the list as applicable. Users can choose only one GENERATE at a time.
Note:

Fields with an Asterisk Mark (*) are Mandatory fields.

GENERATE drop-down

  1. Click the EFFECTIVE YEAR drop-down and select the effective year from the list as applicable. Users can choose only one EFFECTIVE YEAR at a time.

EFFECTIVE YEAR drop-down

  1. By default, the PRINT TYPE drop-down displays the Regular. Users can click the PRINT TYPE drop-down and select the print type from the list as applicable. Users can choose only one PRINT TYPE at a time.

PRINT TYPE drop-down

  1. By default, the LANGUAGE drop-down displays the English. Users can click the LANGUAGE drop-down and select the language from the list as applicable. Users can choose only one LANGUAGE at a time.

LANGUAGE drop-down

  1. By default, the VERSION drop-down displays the Released. Users can click the VERSION drop-down and select either Released or In Progress.

VERSION drop-down

  1. Click the LINE OF BUSINESS drop-down and select the line of business from the list as applicable. Users can choose only one LINE OF BUSINESS at a time.

LINE OF BUSINESS drop-down

  1. By default, the Document Types section displays the first document in the list as selected. Users can choose only one Document Type at a time from the list as applicable.
Note:

Users can utilize the Search document types option to find the appropriate document type from the Document Types list.

For example:

Enter a valid Document Type in the Search document types search box. The Document Type gets searched and appears on the window.

Document Type selection

Search document types search box

  1. Select the Document Name(s) from the Documents list. To select the Document Name(s), click the checkbox(s), and the checkbox(s) gets selected with a checkmark icon. Users can choose one or more Document Name(s) at a time.
Note:

Users can utilize the Search documents option to find the appropriate Document Name from the Documents list.

For example:

Enter a valid Document Name in the Search document search box. The Document Name gets searched and appears on the window.

Document Name(s) selection

Search documents search box

  1. Once the users are done with their Document(s) selection, click the Queue button.

Queue button

  1. The Queue button drop-down gets expanded.

Queue button drop-down

  1. Users can click the appropriate option to Queue the selected Document(s).
Note:

If the user wants to queue the selected Document(s) into the Word File, they can click the Queue Word button. Once the user clicks the Queue Word button, the file gets queued successfully.

If the user wants to queue the selected Document(s) into the Word & PDF File, they can click the Queue Word & PDF button. Once the user clicks the Queue Word & PDF button, the file gets queued successfully.

If the user wants to queue the selected Document(s) into the 508 PDF and Printx, they can click the Queue 508 PDF and Printx button. Once the user clicks the Queue 508 PDF and Printx button, the file gets queued successfully.

Queue button

  1. If the user wants to queue and publish the selected Document(s), click the Queue and Publish button.
Note:

The Queue and Publish functionality generates the Document and then publishes it to Collaborate.

Queue and Publish button

  1. The Generate And Publish Document pop-up window appears.

Generate And Publish Document pop-up window

  1. Click the Estimation Completion Date field and select the Date from the Calendar.
Note:

Users can enter the Estimation Completion Date manually.

Estimation Completion Date field

  1. Click the Assigned To drop-down and select the assigned to name from the list as applicable. Users can choose one or more Assigned To name(s) at a time.
Note:

The Assigned To drop-down displays only users associated with the Simplify Docs application. It will not show external users or users who are not part of the Simplify Docs application.

The selected users will get a notification via email that the Document Workflow is assigned to them.

Assigned To drop-down

  1. The new Assignee gets added.

Newly added Assignee

  1. If the user wants to remove any Assigned To name from the selected list, they can click the x icon.

x icon

  1. The Assigned To name gets removed.
  1. Click the Reviewers drop-down and select the reviewer name from the list as applicable. Users can choose one or more Reviewer's name(s) at a time.

Reviewers drop-down

  1. The new Reviewer's name(s) gets added.

Newly added Reviewer

  1. If the user wants to remove any Reviewer's name from the selected list, they can click the x icon.

x icon

  1. The Reviewer's name gets removed.

Updated Reviewers

  1. If the user wants to add a new reviewer's name to the Reviewers list, they can click the Add New Reviewer button.

Add New Reviewer button

  1. The Add New Reviewer section gets added.

Add New Reviewer section

  1. Click the Name field and enter the name that the user wants to add as a Reviewer.

Name field

  1. Click the Email field and enter the email.

Email field

  1. Click the Add button.

Add button

  1. The new Reviewer name gets added to the Reviewers drop-down.

Newly added Reviewer

  1. If the user wants to add another Reviewer, they can follow the above steps from 24 to 29.
  1. If the user wants to remove any Reviewer's name from the selected list, they can click the x icon.

x icon

  1. The Reviewer's name gets removed.

Updated Reviewers

  1. Click the Comment fields and enter the comment as applicable.
Note:

Comment must be at least Five characters

Comment field

  1. Click the Generate and Publish button.

Generate and Publish button

  1. The Success confirmation message pop-up window appears. Click the Close button.

Success confirmation message pop-up window

  1. Click the Queued Documents tab.

Queued Documents tab

  1. By default, the Documents tab opens.

Documents tab

  1. The newly published Document(s) gets added to the top of the Queued Documents list.
Note:

If the user published the Redline Document(s), then click the Redline tab. The newly published Redline Document(s) gets added to the top of the Redline Document(s) list.

Newly Published Document
