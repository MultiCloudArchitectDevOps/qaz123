Dashboard

The Dashboard window displays/reflects the complete available data in Collaborate, such as FeedBack Rounds, Review Categories, Review Statuses, Delivery Status, and WorkFlow Status.

Dashboard

Dashboard

Access the Dashboard

To access the Dashboard page, follow the steps below:

  1. Navigate to Grid Menu button located on the upper left side of the window. Click the Grid Menu button.

Grid Menu button

  1. The Grid Menu gets expanded.

Expanded Grid Menu

  1. Click the Production Hub expand button.

Production Hub expand button

  1. Click the Collaborate button.

Collaborate button

  1. The Collaborate window opens.

Collaborate window

  1. Click the Dashboard tab.

Dashboard tab

  1. The Dashboard window opens.

Dashboard window

View/Download Data for/from Effective Year/Collateral Type

To view and download data for a specific Effective Year or Collateral Type, follow the steps below:

  1. To access the Dashboard page, follow steps 1 to 7 of the Access the Dashboard process under the Production Hub/Collaborate/Dashboard section of the user guide.
  1. By default, the Dashboard window displays/represents all the data from the beginning.

Data from the beginning

Data from the beginning

  1. Click the Effective Year drop-down and select the effective year as applicable. Users can choose one, more, or all Effective Year(s) at a time.

Effective Year drop-down

  1. Click the Collateral Name drop-down and select the collateral name from the list as applicable. Users can choose one, more ,or all Collateral Name(s) at a time.

Collateral Name drop-down

  1. Click the Apply filters button.

Apply filters button

  1. The Dashboard displays/represents the data for the selected Effective Year and Collateral Name(s).

Dashboard for selected Effective Year and Collateral Name(s)

Dashboard for selected Effective Year and Collateral Name(s)

  1. If the user wants to download the FeedBack Rounds report in .CSV format, click the three-dot menu icon.

Three dot menu icon

  1. Click the Download button and then click the Export to .CSV button.

Export to .CSV button

  1. The FeedBack Rounds report gets downloaded into the .CSV format to the user's local system for their access. Users can open the downloaded report and take necessary action if required.
  1. If the user wants to download the FeedBack Rounds report in Excel format, click the three-dot menu icon.

Three dot menu icon

  1. Click the Download button and then click the Export to Excel button.

Export to Excel button

Three dot menu icon

  1. The FeedBack Rounds report gets downloaded as an image to the user's local system for their access. Users can open the downloaded report and take necessary action if required.
