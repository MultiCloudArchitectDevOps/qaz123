User Management

The User Management tab contains details of all users involved in the review process. Here, users can perform the following functions to manage users in the review process:

  • Add User
  • Edit User
  • Delete User
  • Manage User Group

User Management

Access the User Management

To access the User Management page, follow the steps below:

  1. Navigate to Grid Menu button located on the upper left side of the window. Click the Grid Menu button.

Grid Menu button

  1. The Grid Menu gets expanded.

Expanded Grid Menu

  1. Click the Production Hub expand button.

Production Hub expand button

  1. Click the Collaborate button.

Collaborate button

  1. The Collaborate window opens.

Collaborate window

  1. Click the User Management tab.

User Management tab

  1. The User Management window opens.

User Management window

Add User

The Add User functionality allows the user to create and add a new user.

To add a new User, follow the steps below:

  1. To access the User Management page, follow steps 1 to 7 of the Access the User Management process under the Production Hub/Collaborate/User Management section of the user guide.
  1. Click the Add/Edit User button.

Add/Edit User button

  1. The Add User pop-up window appears.

Add User pop-up window

  1. Click the Name field and enter the name as required.

Name field

  1. Click the Email field and enter the email as required.

Email field

  1. Click the User Groups drop-down and select the group from the list as applicable. Users can choose only one User Group at a time.

User Groups drop-down

  1. Click the Create User button.

Create User button

  1. The User gets created successfully and gets added to the top of the list.

Newly created User

Edit User

The Edit User functionality allows users to edit and update existing user details.

To edit an existing User's details, follow the steps below:

  1. To access the User Management page, follow steps 1 to 7 of the Access the User Management process under the Production Hub/Collaborate/User Management section of the user guide.
  1. Click the checkbox to select the User Name. Once the user clicks the checkbox, the checkbox gets selected with a checkmark icon. Users can choose only one User Name at a time.

User Name selection

  1. Click the Add/Edit User button.

Add/Edit User button

  1. The Edit User pop-up window appears.

Edit User pop-up window

  1. If the user wants to edit/update/modify any data/content from any of the below-listed field(s)/drop-down(s), follow steps 4 to 6 of the Add User process under the Production Hub/Collaborate/User Management section of the user guide:
  • Name
  • Email
  • User Groups

Updating existing User data

  1. Click the Save Changes button.

Save Changes button

  1. The User details/information updated successfully.

Updated User details/information

Delete User

The Delete User functionality allows users to delete the selected user from the list.

To delete a selected User from the list, follow the steps below:

  1. To access the User Management page, follow steps 1 to 7 of the Access the User Management process under the Production Hub/Collaborate/User Management section of the user guide.
  1. Click the checkbox to select the User Name. Once the user clicks the checkbox, the checkbox gets selected with a checkmark icon. Users can choose only one User Name at a time.

User Name selection

  1. Click the Delete User icon.

Delete User icon

  1. The Delete Users pop-up window appears. Click the Delete button.

Delete Users pop-up window

  1. The selected User gets deleted from the list.

Updated User Name list
