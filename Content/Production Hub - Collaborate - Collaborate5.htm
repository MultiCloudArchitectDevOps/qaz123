Previous Versions

The Previous Version section shows all the previous versions of the Document under review, with the details including:

  • Product Name
  • Collaborate Version
  • Workflow Status
  • Date and Timestamp
  • Product Link

  • Check List

To check the Previous Versions, follow the steps below:

  1. To access the Collaborate page, follow steps 1 to 5 of the Access the Collaborate process under the Production Hub/Collaborate/Collaborate section of the user guide.

  1. Click the Eye icon in the Previous Version column for the Document.

Eye icon

  1. The Previous Version pop-up window appears. Users can check/see all Previous Versions of the Document here.

Previous Version pop-up window

  1. To open the Document for the Previous Version, click the Product Link icon in front of the Previous Version that the user wants to open from the Product Link column.

Product Link for Previous Version

  1. Once the user clicks the Product Link icon, the Document for that Version opens in the browser's new tab.

Documents Version

  1. Click the Previous Version X icon to close the pop-up window.

Previous Version X icon

Email Status

The Email Status section shows the status of emails sent to the Reviewers of the assigned Documents.

To check the Email Status, follow the steps below:

  1. To access the Collaborate page, follow steps 1 to 5 of the Access the Collaborate process under the Production Hub/Collaborate/Collaborate section of the user guide.

  1. Click the Eye icon in the Email Status column for the Document.

Eye icon

  1. The Email Status pop-up window appears.

Email Status pop-up window

  1. Users can check/see all the statuses of emails sent to the Reviewers of the assigned Documents here.

Status of Emails

  1. Click the Email Status X icon to close the pop-up window.

Email Status X icon

Reviewers Dashboard

The Reviewers Dashboard functionality offers reviewers a convenient platform to access and review their assigned documents directly from their personalized dashboard. It provides comprehensive details for each document assigned for review.

The Reviewers Dashboard provides detailed information about each document assigned for the review, including:

  • Id
  • Collateral Type
  • Product Name
  • Assigned To
  • Reviewers Involved
  • Queued Date and Time Stamp
  • ECD
  • Collaborate Version
  • Workflow Status
  • Product Link
  • Review Summary
  • Previous Version
  • User Level Status
  • Update Status
